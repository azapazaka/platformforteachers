# Помощник учителя русского языка

Сайт помогает учителю русского языка быстро подготовиться к уроку:

- **Презентация к уроку.** Слайды с правилами, примерами, упражнениями, тестом, рефлексией и домашним заданием. К каждому слайду есть заметки для учителя, к упражнениям — ответы. Файл скачивается в PowerPoint (.pptx), на выбор четыре темы оформления.
- **Краткосрочный план урока (КСП).** Составляется по форме обновлённого содержания образования РК: шапка, цели обучения, цели урока, ход урока (этап/время, действия педагога, действия ученика, оценивание, ресурсы). Есть расширенный вариант: критерии оценивания, языковые цели, ценности, межпредметные связи, дифференциация, рефлексия. Файл скачивается в Word (.docx) или печатается.

Текст генерирует модель через [Groq API](https://console.groq.com).

## Устройство

```
api/                    серверные функции Vercel (ключ Groq хранится только здесь)
  presentation.js       POST /api/presentation
  ksp.js                POST /api/ksp
  _lib/prompts.js       системные промпты для генерации
  _lib/groq.js          запрос к Groq в JSON-режиме, повтор при сбое
  _lib/sanitize.js      проверка структуры ответа модели
src/                    интерфейс на React + Vite
  pages/                главная, презентация, КСП
  lib/exportPptx.js     сборка .pptx (pptxgenjs)
  lib/exportDocx.js     сборка .docx (docx)
```

## Локальный запуск

```bash
npm install
cp .env.example .env   # вставьте GROQ_API_KEY
npm run dev
```

Сайт откроется на http://localhost:5173. Функции из `api/` в режиме разработки обслуживает сам Vite, Vercel CLI не нужен.

## Деплой на Vercel

1. Импортируйте репозиторий на [vercel.com/new](https://vercel.com/new). Фреймворк Vite определится автоматически.
2. В **Settings → Environment Variables** добавьте `GROQ_API_KEY`. По желанию добавьте `GROQ_MODEL` (по умолчанию `llama-3.3-70b-versatile`).
3. Нажмите **Deploy**.

## Переменные окружения

| Переменная     | Обязательна | Описание                                          |
| -------------- | ----------- | ------------------------------------------------- |
| `GROQ_API_KEY` | да          | ключ из https://console.groq.com/keys             |
| `GROQ_MODEL`   | нет         | модель Groq, по умолчанию `llama-3.3-70b-versatile` |
